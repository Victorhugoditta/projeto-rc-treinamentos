RAFAEL CARTAXO — SITE PARA PUBLICAÇÃO
Versão aprovada em 10/10/2026, incluindo a correção do contraste do botão de contato.

CONTEÚDO
HTML, CSS, JavaScript, logo original, foto colorida, imagens ilustrativas e vídeo MP4.
O site é estático: não requer instalação de pacotes, servidor de aplicação ou banco de dados.

PUBLICAR NA VERCEL PELO SEU GITHUB
1. Extraia este ZIP.
2. No repositório Victorhugoditta/projeto-rc-treinamentos, envie os arquivos extraídos para a raiz. O index.html deve ficar na raiz, junto com os CSS e script.js; preserve a pasta assets com seu conteúdo.
3. Substitua os arquivos de mesmo nome. Você pode usar Add file > Upload files no GitHub e confirmar o commit. Não envie apenas o ZIP.
4. Se a Vercel já estiver conectada à branch utilizada, o commit dispara uma nova publicação.
5. Para importar como novo projeto: na Vercel, importe o repositório. Use Framework Preset: Other, Root Directory: raiz, Build Command: vazio e Output Directory: ponto (.). O vercel.json incluído configura publicação estática na raiz.

OUTRAS HOSPEDAGENS
Envie index.html, about.html, arquivos CSS, script.js e assets/ para a pasta pública (por exemplo public_html). Mantenha os nomes e a estrutura. O arquivo vercel.json é específico da Vercel.

VERIFICAÇÃO APÓS PUBLICAR
Abra em computador e celular; confira menu, filtros, seletor de soluções, reprodução do vídeo e contato no Instagram. A revisão visual em navegador/aparelhos reais ainda precisa ser feita.

EDIÇÃO
index.html: textos, links e estrutura.
style.css, executive.css, services.css, dynamic.css: estilos, na ordem carregada pelo HTML.
script.js: menu, efeitos, filtros e seletor.
assets/: imagens e vídeo. Preserve logo-oficial.jpeg como logo oficial.
about.html: encaminhamento para a seção Sobre.

CONTATO E MEDIÇÃO
O contato aponta para o Instagram informado. Não há WhatsApp configurado, formulário, backend, coleta de leads ou ferramenta de analytics instalada. O JavaScript apenas oferece eventos de contato para uma futura integração.
As imagens de temas e o vídeo são ilustrativos, gerados por IA, e isso está informado na página. A foto do Rafael e a logo são os arquivos fornecidos.
